Privacy Policy

Last updated: November 21, 2026

Klip Stüdyo is a personal desktop tool used only by its owner. It does not have a server and does not collect, sell or share personal data with anyone.

Data from TikTok

  • Access token: after the user logs in with TikTok, the access and refresh tokens are stored only on the user's own computer, so the user does not need to log in again for every post.
  • Basic profile (user.info.basic): the display name and avatar are used only to show which TikTok account is connected inside the tool.
  • Video posting (video.publish): used only to upload a video the user selected, when the user presses the post button.

Sharing

No data is sent anywhere except to TikTok's own API when the user posts a video. No analytics, no advertising.

Deleting data

Disconnecting TikTok in the tool deletes the stored tokens. Access can also be removed in TikTok settings (Security and login → Manage app permissions).
